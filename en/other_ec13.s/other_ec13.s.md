### 1. Меметные алгоритмы (Memetic Algorithms)


### Условие

Меметные алгоритмы сочетают эволюционные вычисления (обычно генетический алгоритм) с эвристиками локального поиска. Название происходит от термина «мем», введенного Ричардом Докинзом для обозначения культурных репликаторов. В биологии давний спор о том, могут ли приобретенные при жизни признаки передаваться потомству (например, сильные руки кузнеца), был решен отрицательно центральной догмой молекулярной биологии: информация идет от ДНК к белку, но не наоборот. Однако мемы — это идеи, которые распространяются и могут улучшаться под влиянием опыта их носителей. В алгоритмах мы сначала создаем потомство через селекцию, кроссовер и мутацию, а затем применяем локальный поиск для его улучшения. Это поднимает вопрос: должна ли приспособленность особи оцениваться по ее исходному или улучшенному качеству? Такие алгоритмы также называют гибридными генетическими алгоритмами. 
### Решение

Локальный поиск (меметный шаг) берет созданного операторами потомка и оптимизирует его в локальной окрестности перед оценкой финальной приспособленности. 
```python
import random

def fitness_function(individual):
    # Задача максимизации: считаем сумму элементов
    return sum(individual)

def local_search_lamarck(individual, max_steps=5):
    """Локальный поиск методом восхождения к вершине (Hill Climbing)"""
    current_solution = list(individual)
    current_fitness = fitness_function(current_solution)
    
    for _ in range(max_steps):
        # Случайная мутация (изменение одного гена для поиска в окрестности)
        mutate_idx = random.randint(0, len(current_solution) - 1)
        current_solution[mutate_idx] = 1 - current_solution[mutate_idx]
        new_fitness = fitness_function(current_solution)
        
        # Если стало лучше — закрепляем успех, иначе — откатываем изменения
        if new_fitness > current_fitness:
            current_fitness = new_fitness
        else:
            current_solution[mutate_idx] = 1 - current_solution[mutate_idx]
            
    return current_solution

# Генерируем случайного потомка после кроссовера
raw_offspring = [1, 0, 1, 0, 0, 1, 0]
# Применяем меметное улучшение
optimized_offspring = local_search_lamarck(raw_offspring)

print(f"Потомок до локального поиска: {raw_offspring} (Фитнес: {fitness_function(raw_offspring)})")
print(f"Потомок после локального поиска: {optimized_offspring} (Фитнес: {fitness_function(optimized_offspring)})")
```

### 2. Эволюционные стратегии (Evolutionary Strategies)


### Условие

Главным отличием Эволюционных Стратегий (ЭС) от других эволюционных подходов (таких как ГА) является представление данных. Если ГА используют дискретные или бинарные кодировки, то ЭС работают с векторами вещественных чисел. Операторы также специфичны: мутация выполняется путем добавления случайного Гауссова (нормального) шума к элементам вектора. При этом дисперсия этого шума (шаг мутации) может динамически адаптироваться для каждого локуса индивидуально в процессе оптимизации. Кроссовер и селекция (такие как стратегии (λ, μ) и (λ + μ)) выполняются в стандартном режиме. При использовании кроссовера без позиционного смещения (например, UX) алгоритм приближается к «беспредставленческому». 
### Решение

В ЭС мутация моделирует непрерывные изменения параметров с помощью распределения Гаусса. Параметр `sigma` определяет масштаб шага поиска. 
```python
import random

def es_mutation(individual, sigmas):
    """Мутация ЭС с добавлением случайного Гауссова шума"""
    mutated_individual = []
    
    for gene, sigma in zip(individual, sigmas):
        # Добавляем Гауссова шум со средним 0 и стандартным отклонением sigma
        noise = random.gauss(0, sigma)
        mutated_individual.append(gene + noise)
        
    return mutated_individual

# Особь представлена вектором вещественных чисел (например, координаты)
parent_vector = [2.5, -1.0, 0.0]
# Индивидуальные параметры шага поиска для каждого гена
current_sigmas = [0.1, 0.5, 0.01]

offspring_vector = es_mutation(parent_vector, current_sigmas)
print(f"Родитель ЭС: {[round(x, 3) for x in parent_vector]}")
print(f"Потомок ЭС:  {[round(x, 3) for x in offspring_vector]}")
```

### 3. Алгоритмы оценки распределения (Estimation of Distribution Algorithms)


### Условие

Классический эволюционный алгоритм можно рассматривать как неявное сэмплирование точек в пространстве поиска согласно неизвестному распределению вероятностей на основе популяции и операторов. Алгоритмы оценки распределения (EDA) полностью отказываются от операторов кроссовера и мутации. Они напрямую оценивают распределение вероятностей на основе лучших решений, строят его явную модель и генерируют новые точки из этого распределения. Выразительность модели определяет сложность распределений, которые можно приблизить. Простейшая модель предполагает независимость генов (каждый локус независим), из-за чего она не справляется с эпистатическими (нелинейно зависимыми) задачами. Повышая степень учитываемой взаимосвязи (парные или многомерные взаимодействия), можно аппроксимировать сложные распределения, что является трудной задачей машинного обучения. Основной цикл EDA: - Инициализация модели распределения.
- Пока условие останова не выполнено:- Сэмплировать популяцию из модели распределения; - Обновить модель распределения на основе лучших образцов.


### Решение

Реализуем одномерный алгоритм EDA, где модель хранит вероятности появления единицы для каждого бита, обучаясь на лучших представителях популяции. 

```python
import random

def sample_population_from_model(prob_model, pop_size):
    """Сэмплирование (генерация) популяции на основе вектора вероятностей"""
    population = []
    for _ in range(pop_size):
        individual = [1 if random.random() < p else 0 for p in prob_model]
        population.append(individual)
    return population

def update_eda_model(prob_model, best_individuals, learning_rate=0.2):
    """Обновление вероятностной модели на основе лучших особей"""
    updated_model = list(prob_model)
    num_best = len(best_individuals)
    chrom_len = len(prob_model)
    
    for i in range(chrom_len):
        # Считаем частоту единиц на i-й позиции среди лучших особей
        ones_count = sum(ind[i] for ind in best_individuals)
        frequency = ones_count / num_best
        
        # Сдвигаем модель в сторону успешных частот
        updated_model[i] = (1 - learning_rate) * prob_model[i] + learning_rate * frequency
        
    return updated_model

# Исходная модель: равновероятное распределение для 5 бит
eda_model = [0.5, 0.5, 0.5, 0.5, 0.5]

# Создаем список лучших особей безопасным способом, преобразуя строки
# Это исключает появление пустых запятых из-за сбоев форматирования текста
best_sampled = [
    [int(bit) for bit in "11100"],
    [int(bit) for bit in "11010"],
    [int(bit) for bit in "10101"]
]

# Обновляем вероятностную модель
eda_model = update_eda_model(eda_model, best_sampled)
print(f"Обновленная модель вероятностей EDA: {[round(p, 2) for p in eda_model]}")

# Генерируем новую популяцию по обученной модели
new_pop = sample_population_from_model(eda_model, pop_size=3)
print(f"Сэмплированные из модели потомки: {new_pop}")
```

### 4. Эволюционные вычисления в машинном обучении и моделировании (EC in Machine Learning and Modelling)


### Условие

Основополагающая монография Холланда («Adaptation in Natural and Artificial Systems») не была сфокусирована исключительно на оптимизации. Кен Де Йонг в 1993 году в своей работе на конференции FOGA прямо заявлял: *«Генетические алгоритмы НЕ являются оптимизаторами функций»*. Эволюционные вычисления — это инструмент адаптации и моделирования систем. Ярким примером применения ЭВ в машинном обучении являются **Системы классификаторов (Learning Classifier Systems, LCS)**. LCS используются для задач классификации и обучения с подкреплением (RL). Они объединяют методы RL (в частности, распределение вознаграждения) с ГА, который применяется для обнаружения новых правил. Схемы (шаблоны) здесь явно используются как метод обобщения правил. Более того, ЭВ естественным образом применяются для моделирования самой биологической эволюции, искусственной жизни (Artificial Life) и эволюционной робототехники, где аналитические расчеты популяционной генетики становятся слишком сложными. 
### Решение

Покажем упрощенный принцип работы правила в системах классификаторов (LCS), использующих символ `#` (аналог `*` в теории схем) для обобщения и классификации бинарных признаков данных. 
```python
def match_classifier_rule(condition, data_instance):
    """Проверяет, подходит ли правило классификатора под текущие данные"""
    # '#' выступает в роли символа wild-card (обобщения)
    for c_gene, d_gene in zip(condition, data_instance):
        if c_gene != '#' and int(c_gene) != d_gene:
            return False
    return True

# Набор правил классификатора (Условие -> Действие/Класс)
rules_pool = [
    {"condition": "1#0", "action": "Класс А"},
    {"condition": "00#", "action": "Класс Б"},
    {"condition": "###", "action": "Дефолтный класс"}
]

# Входной вектор признаков от среды
sample_data = [1, 1, 0] # соответствует шаблону "1#0"

print(f"Анализ данных {sample_data} системой классификаторов:")
for rule in rules_pool:
    if match_classifier_rule(rule["condition"], sample_data):
        print(f" -> Сработало правило [{rule['condition']}]. Действие: {rule['action']}")
        break # В реальных LCS правила могут конкурировать за вознаграждение
```
