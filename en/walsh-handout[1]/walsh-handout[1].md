### Летняя серия лекций 2002 — Введение в анализ Уолша


### 1. Понятие преобразования Уолша в контексте ГА

Преобразование Уолша (Walsh transform) представляет собой дискретный бинарный аналог преобразования Фурье. В начале 1980-х годов Альберт Бетке предложил использовать функции Уолша для анализа ландшафтов приспособленности (fitness landscapes). Это позволяет понять, какие именно свойства ландшафта делают задачу сложной для оптимизации с помощью генетических алгоритмов. Базис Уолша позволяет: 

- Строго математически определить интуитивные понятия теории схем (например, «обманчивость» или *deception*).
- Рассчитать коэффициенты Уолша, которые показывают точный вклад линейных и нелинейных компонентов схемы в общую приспособленность.
- Сменить перспективу взгляда на ГА: анализировать не только саму функцию приспособленности, но и динамические свойства операторов смешивания/вариации (mixing matrices).

Математически функция Уолша \(\psi_j(x)\) для строк длины \(\ell \) определяется через побитовое скалярное произведение (операцию XOR и подсчет четности единиц). Для бинарной строки \(x\) и индекса функции \(j\):
\[\psi _{j}(x)=(-1)^{\sum _{i=0}^{\ell -1}j_{i}x_{i}}\]


Любую фитнес-функцию \(f(x)\) можно разложить в линейную комбинацию функций Уолша с коэффициентами \(w_{j}\). Коэффициенты низкого порядка отражают независимый (линейный) вклад отдельных бит, а высокого порядка — их нелинейное взаимодействие (эпистаз).
 
```python
def walsh_function(j, x, l):
    # Вычисление значения функции Уолша для индекса j и строки x длины l
    bit_sum = 0
    for i in range(l):
        # Извлекаем i-й бит из j и x
        bit_j = (j >> i) & 1
        bit_x = (x >> i) & 1
        bit_sum += bit_j * bit_x
    return 1 if bit_sum % 2 == 0 else -1

def walsh_transform(fitness_values, l):
    # Быстрое/прямое преобразование Уолша для списка значений фитнес-функции
    n = 2 ** l
    coefficients = []
    for j in range(n):
        w_j = 0
        for x in range(n):
            w_j += fitness_values[x] * walsh_function(j, x, l)
        coefficients.append(w_j / n)
    return coefficients

# Пример: Пространство из 3 бит (l=3). Фитнес-функция равна числу единиц (Onemax)
l_size = 3
fitness_onemax = [bin(x).count('1') for x in range(2**l_size)]
coefs = walsh_transform(fitness_onemax, l_size)

print("Значения фитнеса (000 до 111):", fitness_onemax)
print("Коэффициенты Уолша:", [round(c, 2) for c in coefs])
```

### 2. Анализ приспособленности и теория схем (Часть II)


Использование преобразования Уолша для анализа фитнес-ландшафтов помогает выявить структуру комбинаторных тупиков. Если в ландшафте доминируют коэффициенты Уолша высокого порядка, это свидетельствует о сильном нелинейном взаимодействии генов (эпистазе). В таких условиях короткие схемы низкого порядка (строительные блоки) направляют поиск в сторону от глобального оптимума. Это явление называют **обманчивостью (deception)** ландшафта.
 
Зная коэффициенты Уолша, можно аналитически рассчитать среднюю приспособленность любой схемы без явного перебора всех ее экземпляров в популяции. Для этого суммируются только те коэффициенты Уолша, индексы которых согласуются со структурой схемы (не зануляются на позициях со знаком `*`).

```python
def analyze_deception_example():
    # Пример анализа: если w_0 (среднее) велико, а коэффициенты первого порядка 
    # направляют алгоритм в противоположную от оптимума сторону, функция "обманчива".
    # Моделируем ландшафт через коэффициенты Уолша напрямую
    # Индексы: 0 (константа), 1 (первый бит), 2 (второй бит), 3 (взаимодействие)
    walsh_coefs = [2.0, -0.5, -0.5, 1.5] # Сильное нелинейное взаимодействие (индекс 3)
    
    # Восстановление фитнес-структуры из коэффициентов для 2-битной задачи
    fitness_recovered = []
    for x in range(4):
        f_x = 0
        for j in range(4):
            # Значение функции Уолша (1 или -1)
            bit_sum = bin(j & x).count('1')
            walsh_val = 1 if bit_sum % 2 == 0 else -1
            f_x += walsh_coefs[j] * walsh_val
        fitness_recovered.append(f_x)
    return fitness_recovered

print("Восстановленный ландшафт приспособленности (00, 01, 10, 11):", analyze_deception_example())
```

### 3. Анализ динамических систем и матриц смешивания (Часть III)

Современные исследования (работы М. Воза и А. Райта) показывают, что преобразование Уолша полезно не только для статического анализа фитнес-функций. Оно применяется для линеаризации и упрощения уравнений, описывающих математическую динамику самого ГА. Матрицы вариации и смешивания (mixing matrices), отражающие эффекты одновременного действия кроссовера и мутации, приобретают блочно-диагональную или более разреженную структуру при переходе в базис Уолша. 

В динамических моделях ГА (модель Воза / Vose Infinite Population Model) состояние популяции представляется вектором вероятностей. Операторы кроссовера и мутации в исходном координатном пространстве описываются громоздкими квадратичными формами. Переход в базис Уолша превращает операцию вычисления следующего поколения в более простую алгебраическую процедуру за счет декомпозиции взаимодействий.
 
```python
import numpy as np

def generate_walsh_matrix(l):
    # Генерация классической матрицы Адамара-Уолша размера (2^l x 2^l)
    n = 2**l
    H = np.zeros((n, n))
    for i in range(n):
        for j in range(n):
            bit_sum = bin(i & j).count('1')
            H[i, j] = 1 if bit_sum % 2 == 0 else -1
    return H / np.sqrt(n)

l_bits = 2
W_matrix = generate_walsh_matrix(l_bits)
print(f"Матрица преобразования Уолша для {l_bits} бит:\n", W_matrix)
```

### 4. Заключение и библиография (Часть IV)

Анализ Уолша — это не самостоятельный изолированный инструмент, а математическая линза, меняющая перспективу. Она позволяет совмещать теорию схем Холланда с методами анализа дискретных динамических систем. **Основные исторические вехи и публикации:** 

- **Бетке (1980):** Первое применение преобразования для анализа оптимизационных свойств ГА в докторской диссертации.
- **Голдберг (1989):** Популяризация анализа Уолша, детальное введение в математику «обманчивых ландшафтов».
- **Воз и Райт (1998–1999):** Фундаментальный прорыв. Применение преобразования к операторам смешивания популяции, создание строгой математической основы Простого Генетического Алгоритма (SGA).


Для практической проверки гипотез о сложности задач часто вычисляют так называемую *метрику дисперсии Уолша* или оценивают распределение энергии по порядкам коэффициентов, определяя уровень нелинейности.

```python
def calculate_landscape_nonlinearity(coefficients):
    # Оценка «энергии» нелинейных взаимодействий
    # Нулевой коэффициент — это среднее значение, его не учитываем
    linear_energy = 0.0
    nonlinear_energy = 0.0
    
    for j in range(1, len(coefficients)):
        order = bin(j).count('1') # Порядок коэффициента Уолша
        if order == 1:
            linear_energy += coefficients[j] ** 2
        elif order > 1:
            nonlinear_energy += coefficients[j] ** 2
            
    total_energy = linear_energy + nonlinear_energy
    return (nonlinear_energy / total_energy) if total_energy > 0 else 0.0

# Возьмем коэффициенты из примера 2
test_coefs = [2.0, -0.5, -0.5, 1.5]
nonlin_ratio = calculate_landscape_nonlinearity(test_coefs)
print(f"Доля нелинейной энергии в ландшафте: {nonlin_ratio:.2%} (чем выше, тем сложнее для ГА)")
```
