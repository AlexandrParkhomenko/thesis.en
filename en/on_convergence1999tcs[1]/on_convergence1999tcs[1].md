# On Convergent Rate of Genetic Algorithms

Jun He and Lishan Kang

# Abstract

Bounds on the convergent rate is an important problem in the foundations of genetic algorithm. This paper obtained some bounds on the convergent rate of genetic algorithms by Markov chain theory. The main result is that the algorithms convergence in geometric rate under the meaning of probability measure.

# I. INTRODUCTION

When genetic algorithms [4] [6] [7] are used to solve optimization problems, we should answer two basic theoretical questions: (1) to prove the convergence of genetic algorithms; (2) to analysis the efficiency of the algorithms, in some way, to give bounds on the convergent rate. Many works [5] [8] [19] has been done to answer question (1), and obtained some good results (such as in Rudolph [19]).

But few results about the efficiency of the genetic algorithms are obtained. B¨ack [2] and M¨uhlenbein [15] made the firs steps in this direction, Suzuki [21] derived a low-bound of the convergent rate for the simple genetic algorithms.

This paper gives a general answer to question (2). Our basic idea is that: in numerical optimization, if $\xi _ { t }$ is the iterative solution at time t and $\xi ^ { * }$ is the exact solution, then we should prove $\parallel \xi _ { t } - \xi ^ { * } \parallel \to 0$ as $t \to 0$ and estimate the error distance $\parallel \xi _ { t } - \xi ^ { * } \parallel$ . This idea is still useful in the genetic algorithms (or stochastic algorithms in general), in the stochastic version, $\xi _ { t }$ and $\xi ^ { * }$ become random variables. Denote the probability distribution of $\xi _ { t }$ and $\xi ^ { * }$ as $\mu _ { t }$ and $\pi$ respectively, and $\parallel \mu _ { t } - \pi \parallel$ as their total variation distance, then question (1) is to prove $\parallel \mu _ { t } - \pi \parallel \to 0$ as $t \to \infty$ , and question (2) is to estimate the bounds of $\parallel \mu _ { t } - \pi \parallel$ .

By using the results of Markov chain theory in [12] [13] [17] [18], we give answers to questions (1) and (2). Our main results is that the genetic algorithms with elite strategy not only converge: $\parallel \mu _ { t } - \pi \parallel \to 0$ as $t \to \infty$ , but also converge in a geometric rate: k µt − π k≤ (1 − δ)[t/t0].

Section 2 establishes a Markov chain model for genetic algorithms. Section 3 introduces some results about convergent rate of Markov chain. We apply them to genetic algorithm and get some theorems about the convergent rate in Section 4. We come to our conclusions in Section 5.

# II. MARKOV CHAIN MODEL (EVOLUTION) FOR GENETIC ALGORITHMS

This paper divide the usual genetic algorithms into two classes: genetic algorithms whose mutation, crossover and selection operator are not changed as time; and genetic evolution algorithms [8] whose operators are variable as time. The section shows that the mathematical model of genetic algorithms is a stationary Markov chain, and the model of genetic evolution algorithms is a non-stationary Markov chain. We make some prior properties for these Markov chain from observation on genetic (evolution) algorithms.

Theorem 3: For any Markov chain $\{ \xi ( t ) ; t \in Z ^ { + } \}$ defined on measurable space $( X ^ { N } , { \mathfrak { B } } ( X ^ { N } ) )$ with transition probability function $P ( \mathbf { x } , A )$ , if the chain is aperiodic and Doeblin’s condition holds, that is, there exists a probability measure $\phi$ on $B ( X )$ and some $\varepsilon > 0$ , $\delta > 0$ , $t _ { 0 } \in Z ^ { + }$ such that, whenever set $A \in B ( X ^ { N } )$ with $\phi ( A ) > 0$ :

$$
\underset { \mathbf { x } \in X ^ { N } } { \operatorname* { i n f } } P ( 0 , t _ { 0 } ; \mathbf { x } , A ) > \delta
$$

then the convergence rate is geometrically fast, that is for any $\mathbf { x } \in X ^ { N }$ :

\parallel \mu _ { t } - \pi \parallel \le ( 1 - \delta ) ^ { [ t / t _ { 0 } ] }

where $\mu _ { t } ( A ) = P ( \xi ( t ) \in A ; \xi ( 0 ) = \mathbf { x } )$ .

Let’s consider the M¨uhlenbein’s ONE-MAX problem [15]:

$$

The genetic algorithms used for solving the problem is:

(1) The mutation operator is that: for each individual $x$ in population $\mathbf { x }$ , let its each bit $s _ { i }$ turn into it complement with   
probability $p$ , but the best individual in the population does not join in the mutation. (2) The crossover rate is 0. (3) The selection operator is that: to define a survive probability $\beta _ { i }$ to each individual $x _ { i }$ according to its fitness, and then   
use the wheel roulette selection, but the best individual in the population always has at least one offspring. We can easily verify the algorithm satisfies Property (1), (2) and (3) holds. $$

$$

Property (3.c): This is direct from the elite strategy.

# V. CONCLUSIONS AND DISCUSSIONS

We divide the usual genetic algorithms into two classes: one is genetic algorithms which has fixed mutation, crossover and selection operators, whose mathematical model is a stationary Markov chain; another is genetic evolution algorithm which has variable mutation, crossover and selection operators, whose mathematical model is a non-stationary Markov chain.

This paper gives the bounds for convergence rate on genetic algorithms. Our main conclusions are that: For the genetic algorithm given by Fig. 1, if it satisfies Property (1), (2) and (3), then it converges in a geometric rate: $\parallel \mu _ { t } - \pi \parallel \widecheck { < } \left( 1 - \delta \right) ^ { \left[ t / t _ { 0 } \right] }$ .

For the genetic evolution algorithm given by Fig 3, if it satisfies Property (4), (5) and (6), then it converges in a following rate: $\begin{array} { r } { \parallel \mu _ { t } - \pi \parallel < ( 1 - \delta ) ^ { [ t / t _ { 0 } ] ^ { - } - 1 } + \sum _ { t = t _ { 0 } } ^ { \bar { \infty } } a _ { t } / \delta } \end{array}$ .

But there are still many questions which are worth discussing further: (1) The bounds given in this paper is for the general case. For a problem and its genetic algorithms, we must compute the first visit time and first-visit probability of the Markov chain. It needs a precise estimation, sometimes it is a difficult thing. (2) Our discussions is mainly to the elite strategy (Rodulph[19] have pointed this is an important condition for global convergence). For the non-elite strategy, it should have more discussion. (3) The form of genetic evolution algorithm may take many different forms, its analysis is difficult. One of the questions is that although Property (4.c), (5.c) and (6.c) doesn’t holds, the algorithms is still convergence, so how to estimate the bounds of convergence rate is interesting.
