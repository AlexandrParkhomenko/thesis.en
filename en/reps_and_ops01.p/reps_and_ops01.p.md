### 1. Кодирование Грея: Математическое ожидание и дисперсия отклонения при мутации


### Условие

Вычислите математическое ожидание абсолютного отклонения закодированного целого числа, полученного в результате однократной равномерно выбранной точечной мутации в 4-геновой бинарной хромосоме, при стандартном бинарном кодировании и при рефлексивном бинарном кодировании Грея. Также вычислите дисперсию этого математического ожидания. Напишите компьютерную программу для точного расчета. *Подсказка:* Всего существует \(2^4 = 16\) возможных хромосом. Каждая имеет 4 возможных положения для одиночной точечной мутации. Таким образом, общее количество элементарных исходов для расчета средних показателей составляет \(16 \times 4 = 64\). По определению точечной мутации все они равновероятны. 
### Решение

При стандартном бинарном кодировании мутация бита на позиции \(p\) (где \(p \in \{0, 1, 2, 3\}\) справа налево) всегда изменяет значение числа ровно на \(2^{p}\), независимо от значений остальных битов. Математическое ожидание изменения составит:
\[\mu _{\text{std}}=\frac{2^{0}+2^{1}+2^{2}+2^{3}}{4}=\frac{1+2+4+8}{4}=3.75\]

В кодировании Грея величина и знак изменения нелинейно зависят от исходного состояния хромосомы. Точный перебор всех 64 исходов позволяет вычислить точные аналитические параметры распределения отклонений. 
```python
import numpy as np

def binary_to_gray(n):
    return n ^ (n >> 1)

def gray_to_binary(g):
    b = 0
    while g > 0:
        b ^= g
        g >>= 1
    return b

# Собираем массивы всех возможных отклонений (разностей до и после мутации)
std_deviations = []
gray_deviations = []

for initial_val in range(16):
    std_chrom = initial_val
    gray_chrom = binary_to_gray(initial_val)
    
    # Инвертируем поочередно каждый из 4-х бит
    for bit_pos in range(4):
        mask = 1 << bit_pos
        
        # Эффект мутации в стандартном бинарном коде
        mut_std = std_chrom ^ mask
        std_deviations.append(abs(mut_std - initial_val))
        
        # Эффект мутации в коде Грея
        mut_gray_chrom = gray_chrom ^ mask
        mut_gray_val = gray_to_binary(mut_gray_chrom)
        gray_deviations.append(abs(mut_gray_val - initial_val))

# Вычисление статистических параметров
mean_std = np.mean(std_deviations)
var_std = np.var(std_deviations)

mean_gray = np.mean(gray_deviations)
var_gray = np.var(gray_deviations)

print(f"Стандартное кодирование: Ожидание = {mean_std:.2f}, Дисперсия = {var_std:.2f}")
print(f"Кодирование Грея:        Ожидание = {mean_gray:.2f}, Дисперсия = {var_gray:.2f}")
```

### 2. Проблемы перестановок и частично соответствующий кроссовер (PMX)


### Условие

Задачи оптимизации последовательностей (Job Shop Scheduling) и размещения полезной нагрузки (Bin Packing) используют перестановочное представление хромосом, где стандартный линейный кроссовер неприменим из-за появления дубликатов и пропусков. Реализуйте **Частично соответствующий кроссовер (Partially Matched Crossover, PMX)**. Алгоритм должен равномерно выбирать две точки разреза между \(1\) и \(\ell-1\), определять взаимное отображение аллелей родителей \(a_i \leftrightarrow b_i\) внутри окна разреза, а внешние позиции заполнять элементами родителей по цепочке замен во избежание дубликатов. 
### Решение

PMX сохраняет порядок и состав элементов перестановки. Ниже приведена исправленная реализация, которая исключает пересечения и зацикливания элементов при переносе генов родителей. 
```python
import random

def pmx_crossover(parent1, parent2):
    size = len(parent1)
    child1 = [None] * size
    child2 = [None] * size
    
    # Выбираем случайные точки разреза (минимум 1 элемент внутри окна)
    cx_point1 = random.randint(0, size - 2)
    cx_point2 = random.randint(cx_point1 + 1, size - 1)
    
    # Копируем центральные сегменты напрямую от родителей
    child1[cx_point1:cx_point2+1] = parent1[cx_point1:cx_point2+1]
    child2[cx_point1:cx_point2+1] = parent2[cx_point1:cx_point2+1]
    
    seg1 = parent1[cx_point1:cx_point2+1]
    seg2 = parent2[cx_point1:cx_point2+1]
    
    # Заполняем внешние позиции для первого потомка
    for i in range(size):
        if cx_point1 <= i <= cx_point2:
            continue
        val = parent2[i]
        # Если элемент уже скопирован в центральный сегмент, идем по цепочке соответствий
        while val in seg1:
            idx = seg1.index(val)
            val = seg2[idx]
        child1[i] = val
        
    # Заполняем внешние позиции для второго потомка
    for i in range(size):
        if cx_point1 <= i <= cx_point2:
            continue
        val = parent1[i]
        while val in seg2:
            idx = seg2.index(val)
            val = seg1[idx]
        child2[i] = val
        
    return child1, child2, (cx_point1, cx_point2)

# Пример работы на 5-ти городах TSP (A=1, B=2, C=3, D=4, E=5)
p1 = [1, 2, 3, 4, 5]
p2 = [5, 4, 3, 2, 1]
ch1, ch2, points = pmx_crossover(p1, p2)
print(f"Точки разреза (индексы): {points[0]} и {points[1]}")
print(f"Потомок 1: {ch1}\nПотомок 2: {ch2}")
```

### 3. Операторы специализированной мутации для перестановок


### Условие

Одиночная точечная мутация (замена одного бита или символа на другой) в задаче перестановок гарантированно приводит к невалидному решению, так как нарушается уникальность элементов. Разработайте корректный оператор мутации для перестановок на примере **мутации обмена (Swap Mutation)**. Для более мощных алфавитов взвешивайте вероятность выбора мутирующего аллеля пропорционально его абсолютному расстоянию от текущего гена, исключая выбор самого себя. 
### Решение

Мутация обмена (Swap) выбирает два случайных гена в хромосоме и меняет их местами, сохраняя исходный набор элементов неизменным. 
```python
import random

def swap_mutation(chromosome, mutation_rate=0.5):
    if random.random() < mutation_rate:
        mutated = list(chromosome)
        size = len(mutated)
        # Выбираем два разных случайных индекса для обмена
        idx1, idx2 = random.sample(range(size), 2)
        mutated[idx1], mutated[idx2] = mutated[idx2], mutated[idx1]
        return mutated
    return chromosome

# Пример мутации перестановки городов коммивояжера
parent_route = ['A', 'C', 'D', 'E', 'B']
mutated_route = swap_mutation(parent_route, mutation_rate=1.0)
print(f"Исходный маршрут: {parent_route}")
print(f"После Swap-мутации: {mutated_route}")
```

### 4. Эффективная реализация операторов через битовые маски и биномиальное распределение


### Условие

Для повышения скорости работы генетического алгоритма операторы должны быть реализованы эффективно. Напишите программу, демонстрирующую побитовую реализацию операторов мутации (\(a \oplus m\)) и однородного кроссовера (UX) с помощью масок. Вместо медленного побитового сэмплирования Бернулли для построения маски длинных строк примените оптимизированный подход: сначала сэмплируйте общее ожидаемое количество успехов \(n\) из **биномиального распределения** \(P(n \mid \ell, p)\), а затем случайным образом без возвращения установите \(n\) бит в маске в состояние 1. Это повышает эффективность генерации маски примерно в \(1/p\) раз. 
### Решение

Побитовые операции в Python над целыми числами выполняются на низком уровне С-кода ядра, что обеспечивает максимальное быстродействие генетического поиска. 
```python
import random
import numpy as np

def generate_efficient_mask(length, p):
    """Генерирует бинарную маску через сэмплирование из биномиального распределения."""
    # Шаг 1: Узнаем точное число битов, которые должны перевернуться
    n_mutations = np.random.binomial(length, p)
    
    # Шаг 2: Выбираем уникальные позиции для установки единиц
    mutation_positions = random.sample(range(length), n_mutations)
    
    # Шаг 3: Собираем маску в виде целого числа
    mask = 0
    for pos in mutation_positions:
        mask |= (1 << pos)
    return mask

def bitwise_uniform_crossover(parent1, parent2, mask):
    """Побитовый UX кроссовер: (mask & parent1) | (~mask & parent2)"""
    # В Python инверсия ~mask для знаковых чисел требует маскирования по длине строки
    # Предположим, длина хромосомы равна 8 битам
    bit_length_mask = 0b11111111
    comp_mask = (~mask) & bit_length_mask
    return (mask & parent1) | (comp_mask & parent2)

# Пример работы операторов над 8-битными хромосомами
p1_bin = 0b11110000  # Десятичное 240
p2_bin = 0b00001111  # Десятичное 15

# Генерируем маску для UX кроссовера с вероятностью p=0.5
ux_mask = generate_efficient_mask(length=8, p=0.5)
child_bin = bitwise_uniform_crossover(p1_bin, p2_bin, ux_mask)

print(f"Родитель 1: {bin(p1_bin)[2:]:>08}")
print(f"Родитель 2: {bin(p2_bin)[2:]:>08}")
print(f"Маска UX:   {bin(ux_mask)[2:]:>08}")
print(f"Потомок UX: {bin(child_bin)[2:]:>08}")
```
