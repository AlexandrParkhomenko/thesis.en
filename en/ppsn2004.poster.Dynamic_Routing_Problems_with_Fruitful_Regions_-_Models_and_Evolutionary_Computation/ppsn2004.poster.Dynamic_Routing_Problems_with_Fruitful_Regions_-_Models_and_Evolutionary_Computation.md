### 1. Контекст задачи и онлайн-маршрутизация с ограничениями


### Условие

Исследуется задача онлайн-маршрутизации (on-line routing), в которой запросы на обслуживание клиентов поступают в режиме реального времени прямо во время работы алгоритма. Разрабатывается эволюционный алгоритм (ЭА), способный направлять транспортные средства в перспективные, «плодородные» регионы (fruitful regions). Полная математическая модель учитывает следующие ключевые ограничения: - **Вместимость (Capacity)** каждого транспортного средства.
- **Допустимое время доставки (Delivery time allowed)** груза на центральный склад (депо).


### Решение

В онлайн-маршрутизации хромосома ГА часто кодирует стратегию распределения или приоритеты грузов. Напишем базовый декодер на Python, который распределяет поступающие грузы по транспортным средствам с учетом их максимальной вместимости. 
```python
def greedy_route_decoder(vehicle_capacity, num_vehicles, loads_weights):
    # Инициализируем транспортные средства: текущая загрузка каждого равна 0
    vehicles = [0] * num_vehicles
    # Списки для хранения индексов грузов, распределенных на каждую машину
    routes = [[] for _ in range(num_vehicles)]
    unassigned_loads = []
    
    for i, weight in enumerate(loads_weights):
        assigned = False
        # Пытаемся поместить груз в первое свободное по вместимости авто
        for v_idx in range(num_vehicles):
            if vehicles[v_idx] + weight <= vehicle_capacity:
                vehicles[v_idx] += weight
                routes[v_idx].append(i)
                assigned = True
                break
        if not assigned:
            unassigned_loads.append(i)
            
    return routes, vehicles, unassigned_loads

# Тестовые данные: 3 машины с вместимостью 2, и 9 грузов (весом по 1)
cap = 2
v_count = 3
loads = [1, 1, 1, 1, 1, 1, 1, 1, 1]

assigned_routes, final_loads, missed = greedy_route_decoder(cap, v_count, loads)
print("Распределение грузов по машинам (индексы):", assigned_routes)
print("Финальный вес на каждой машине:", final_loads)
print("Грузы, которые не поместились:", missed)
```

### 2. Упреждающая маршрутизация и самоадаптация (Anticipatory Routing)


### Условие

**Упреждающая маршрутизация (Anticipatory routing)** заключается в передислокации свободных транспортных средств к потенциальным клиентам, которые еще не успели отправить официальный запрос на обслуживание (например, перемещение к гипотетической точке C₃). Знания о вероятном спросе пользователей закладываются в эволюционный алгоритм. Он выполняет упреждающую маршрутизацию с помощью **самоадаптивной схемы (self-adaptive scheme)**. В ходе исследования тестируются два варианта системы: один использует механизмы упреждения, а второй — нет. 
### Решение

Самоадаптация в ГА означает, что параметры алгоритма (например, склонность к упреждающему движению `anticipation_rate`) кодируются прямо в хромосому особи и эволюционируют вместе с решением. Напишем пример мутации такой самоадаптивной хромосомы. 
```python
import random

def self_adaptive_mutation(chromosome):
    # Структура хромосомы: [маршрут_машины_1, маршрут_машины_2, ..., anticipation_rate]
    # Последний элемент — это внутренний параметр склонности к упреждению (от 0.0 до 1.0)
    mutated_chrom = list(chromosome)
    
    # Извлекаем текущий параметр адаптации
    current_rate = mutated_chrom[-1]
    
    # Мутируем сам параметр с помощью Гауссова шума (самоадаптация)
    new_rate = current_rate + random.gauss(0, 0.05)
    # Удерживаем параметр в рамках [0.0, 1.0]
    new_rate = max(0.0, min(1.0, new_rate))
    mutated_chrom[-1] = new_rate
    
    # Обычная мутация маршрута (например, случайная смена точки назначения)
    route_idx = random.randint(0, len(mutated_chrom) - 2)
    mutated_chrom[route_idx] = random.randint(1, 100) # новая зона дежурства
    
    return mutated_chrom

# Пример: Машина 1 едет в зону 12, Машина 2 в зону 45, текущий уровень упреждения 0.3
parent = [12, 45, 0.3]
child = self_adaptive_mutation(parent)

print(f"Родительская хромосома (параметр упреждения {parent[-1]:.2f}): {parent}")
print(f"Дочерняя хромосома  (параметр упреждения {child[-1]:.2f}): {child}")
```

### 3. Симуляционный поток и оценка результатов (Simulation Flow & Experiments)


### Условие

Для верификации подходов проводится серия симуляционных экспериментов. Главным измеряемым показателем является доля грузов, которые были успешно транспортированы за один запуск, усредненная по результатам **1200 прогонов**. В ходе экспериментов было обнаружено явление **фазового перехода (phase transition)**, характеризующееся нижним переходом (синяя стрелка на графике) и верхним переходом (красные стрелки). Самоадаптивный механизм доказал свою эффективность: он успешно контролирует интенсивность упреждающей маршрутизации и применяет её исключительно там, где она приносит реальную выгоду для логистической сети. Данная работа является частью проекта DEAL и поддержана в рамках голландской энергетической программы EET. 
### Решение

Для оценки эффективности двух стратегий (с упреждением и без) обычно пишется симуляционный стенд, собирающий статистику по множеству прогонов (в оригинале — 1200). Напишем скрипт, моделирующий агрегацию результатов таких испытаний. 
```python
import numpy as np

def run_simulation_experiment(strategy_type, total_runs=1200):
    # Моделируем случайные исходы 1200 симуляций для двух типов стратегий
    # Симулируем долю успешно доставленных грузов (значения от 0.0 до 1.0)
    if strategy_type == "with_anticipation":
        # Стратегия с упреждением дает более высокий средний результат
        results = np.random.normal(loc=0.88, scale=0.04, size=total_runs)
    else:
        # Стратегия без упреждения в условиях динамического спроса работает хуже
        results = np.random.normal(loc=0.74, scale=0.06, size=total_runs)
        
    # Ограничиваем диапазон долей от 0 до 1
    results = np.clip(results, 0.0, 1.0)
    
    # Считаем среднюю долю успешных доставок
    mean_success_fraction = np.mean(results)
    return mean_success_fraction

# Запускаем оценку экспериментов
success_rate_pure = run_simulation_experiment("no_anticipation")
success_rate_adaptive = run_simulation_experiment("with_anticipation")

print(f"Результаты усреднения по 1200 запускам:")
print(f" -> Базовая стратегия (без упреждения): {success_rate_pure:.2%}")
print(f" -> Самоадаптивная стратегия (с упреждением): {success_rate_adaptive:.2%}")
```
