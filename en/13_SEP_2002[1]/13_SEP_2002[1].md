### Работают ли ГА? Теорема схем и Гипотеза строительных блоков


### 1. Понятие схемы (Schema)


### Условие

Схема — это шаблон для описания подмножества бинарных строк сходной структуры с использованием символа подстановки `*` (означает «0 или 1»). 

- **Пример:** Схема `*1` соответствует строкам `01` и `11`. Эти строки являются *экземплярами* схемы `*1`.
- **Порядок схемы (Order, o(H)):** Количество фиксированных (определенных) бит в схеме (то есть количество нулей и единиц).
- **Определяющая длина (Defining length, d(H)):** Расстояние между крайними фиксированными позициями схемы. Например, для схемы `1****1` определяющая длина равна 5 (разница индексов 5 - 0 = 5).
- **Средняя приспособленность схемы:** Равна среднему арифметическому приспособленностей всех экземпляров данной схемы, присутствующих в текущей популяции.


### Решение

В генетических алгоритмах схемы помогают теоретически описать, как ведут себя успешные фрагменты хромосом в процессе эволюции. 
```python
def get_schema_properties(schema_str):
    # Удаляем пробелы, если они есть
    s = schema_str.replace(" ", "")
    
    # Порядок схемы - это количество символов, отличных от '*'
    order = sum(1 for char in s if char != '*')
    
    # Определяющая длина - расстояние между первым и последним фиксированным битом
    fixed_indices = [i for i, char in enumerate(s) if char != '*']
    
    if len(fixed_indices) > 1:
        defining_length = fixed_indices[-1] - fixed_indices[0]
    else:
        defining_length = 0
        
    return order, defining_length

# Пример для схемы "1 * * * * 1"
schema = "1****1"
o, d = get_schema_properties(schema)
print(f"Схема: {schema} | Порядок o(H) = {o} | Определяющая длина d(H) = {d}")
```

### 2. Теорема схем: Селекция (Математическое ожидание)


### Условие

- **Интуитивно:** Более приспособленные схемы имеют больше шансов выжить и размножиться.
- **Формально:** Математическое ожидание количества экземпляров схемы H в следующем поколении t+1 под влиянием только оператора селекции вычисляется по формуле:

\[E(m(H,t+1))=\frac{\widehat{u}(H,t)}{\overline{f}(t)}\times m(H,t)\]

Где: 

- m(H, t) — количество экземпляров схемы H в момент времени t.
- E(x) — математическое ожидание величины x.
- û(H, t) — наблюдаемая средняя приспособленность схемы H в момент времени t.
- \(\overline{f}(t)\) — средняя приспособленность всей популяции в момент времени t.


### Решение

Если приспособленность схемы выше средней приспособленности популяции (\(\widehat{u}(H, t) > \overline{f}(t)\)), то доля этой схемы в популяции будет экспоненциально расти от поколения к поколению.

```python
def expected_instances_selection(m_t, u_H, f_avg):
    # Расчет количества экземпляров схемы после селекции
    return (u_H / f_avg) * m_t

# Пример: 5 экземпляров схемы со средней приспособленностью 15.0 
# при средней приспособленности популяции 10.0
m_t1 = expected_instances_selection(m_t=5, u_H=15.0, f_avg=10.0)
print(f"Ожидаемое количество экземпляров схемы после селекции: {m_t1:.2f}")
```

### 3. Теорема схем: Кроссовер и Мутация


### Условие

- **Кроссовер (Интуитивно):** При одинаковой приспособленности кроссовер чаще сохраняет более короткие схемы с меньшим порядком. Длинные схемы легче разрушить при разрезе.
- **Кроссовер (Формально):** Вероятность \(S_c(H)\), что схема H переживет одноточечный кроссовер, ограничена снизу:

\[S_{c}(H)\geqslant 1-p_{c}\left(\frac{d(H)}{\ell -1}\right)\]

Где \(p_{c}\) — вероятность кроссовера, d(H) — определяющая длина, \(\ell \) — общая длина хромосомы. - **Мутация (Интуитивно):** Чем меньше бит зафиксировано в схеме (ниже порядок), тем меньше на нее влияет мутация.
- **Мутация (Формально):** Вероятность \(S_m(H)\), что схема H выживет после побитовой мутации:

\[S_{m}(H)=(1-p_{m})^{o(H)}\]

Где \(p_{m}\) — вероятность мутации одного бита, o(H) — порядок схемы. 

### Решение

Кроссовер представляет опасность для схем с большой определяющей длиной d(H), так как точка разрыва с высокой вероятностью попадет внутрь схемы. Мутация же опасна для схем с высоким порядком o(H), так как изменение любого из фиксированных бит разрушает принадлежность строки к этой схеме. 
```python
def prob_survival_crossover(p_c, d_H, l_len):
    return 1.0 - p_c * (d_H / (l_len - 1))

def prob_survival_mutation(p_m, o_H):
    return (1.0 - p_m) ** o_H

# Параметры: pc=0.7, pm=0.01, длина хромосомы L=20
# Схема с d(H)=5 и o(H)=3
s_c = prob_survival_crossover(0.7, 5, 20)
s_m = prob_survival_mutation(0.01, 3)

print(f"Вероятность пережить кроссовер: {s_c:.4f}")
print(f"Вероятность пережить мутацию: {s_m:.4f}")
```

### 4. Итоговая теорема схем Холланда и Гипотеза строительных блоков


### Условие

Объединяя селекцию, кроссовер и мутацию, мы получаем **Теорему схем Холланда (Holland's Schema Theorem)**: \[E(m(H,t+1))\geqslant \frac{\widehat{u}(H,t)}{\overline{f}(t)}\cdot m(H,t)\cdot \left[1-p_{c}\left(\frac{d(H)}{\ell -1}\right)\right]\cdot (1-p_{m})^{o(H)}\]

- **Неформальный вывод:** Короткие схемы низкого порядка с приспособленностью выше средней будут экспоненциально размножаться в популяции.
- **Гипотеза строительных блоков (Building Block Hypothesis):** Утверждает, что генетический алгоритм ищет оптимальные решения, комбинируя с помощью кроссовера такие короткие, высокоприспособленные схемы низкого порядка (называемые *строительными блоками*) в схемы более высокого порядка.
- **Критика:** Это именно *гипотеза*, а не доказанная теорема. Она вызывает много споров в научном сообществе (работы D. Whitley, M. Vose). Некоторые исследователи (например, R. Watson) предполагают, что строительные блоки могут иметь принципиально иную природу, отличную от классических схем Холланда.


### Решение

Ниже приведен симулятор, вычисляющий гарантированное математическое ожидание количества экземпляров конкретной схемы в следующем поколении на основе комплексной формулы Холланда. 

```python
def holland_schema_theorem(m_t, u_H, f_avg, p_c, d_H, l_len, p_m, o_H):
    # Базовый рост за счет селекции
    selection_factor = u_H / f_avg
    
    # Выживаемость структуры схемы
    crossover_survival = prob_survival_crossover(p_c, d_H, l_len)
    mutation_survival = prob_survival_mutation(p_m, o_H)
    
    # Итоговое минимальное ожидаемое количество по Теореме схем
    expected_m = m_t * selection_factor * crossover_survival * mutation_survival
    return max(0.0, expected_m)

# Пример расчета:
# В популяции длины хромосом 50 есть 10 экземпляров схемы.
# Схема эффективна (u_H=25, f_avg=20), короткая (d_H=4) и имеет низкий порядок (o_H=2).
# Параметры алгоритма: pc=0.6, pm=0.005
next_gen_instances = holland_schema_theorem(
    m_t=10, u_H=25, f_avg=20, 
    p_c=0.6, d_H=4, l_len=50, 
    p_m=0.005, o_H=2
)

print(f"Минимально ожидаемое число экземпляров схемы в следующем поколении: {next_gen_instances:.2f}")
```
