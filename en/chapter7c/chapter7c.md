### Визуализация ландшафтов приспособленности на примере функции De Jong F1


### 1. Различие между фенотипическим ландшафтом и генотипическим пространством


### Условие

Тестовая функция Де Жонга F1 (De Jong's F1 test problem) направлена на минимизацию значений приспособленности (фитнеса), где оптимальные решения сгруппированы вокруг центра 3D-поверхности. В данном примере каждая из трех координат кодируется в виде 10-битного бинарного гена. Фенотипический оптимум равен `0`, а ближайшие к нему по значению точки — это `-0.01` и `+0.01`. В генотипическом пространстве поиска ГА (в виде битовых строк) эти три близких значения кодируются совершенно по-разному: `0 = 1000000000`, `-0.01 = 0111111111` и `+0.01 = 1000000001`. Огромный разрыв в генотипическом пространстве между `0` и `-0.01` (называемый хэмминговым обрывом) визуально не заметен на непрерывном 3D-графике приспособленности. Однако подобные скрытые различия наглядно проявляются при специализированной визуализации генотипического пространства поиска. 
### Решение

В генетических алгоритмах критически важно понимать разницу между фенотипом (реальным числом) и генотипом (битовой строкой). Изменение всего одного бита (мутация) может привести к колоссальному скачку в числовом значении, если инвертируется старший знаковый бит. 
```python
def decode_10bit_signed(bit_string):
    # Декодирование 10-битной строки в числовом диапазоне
    # Для демонстрации используем пример из текста, сопоставляя строки числам
    if bit_string == "1000000000":
        return 0.0
    elif bit_string == "0111111111":
        return -0.01
    elif bit_string == "1000000001":
        return 0.01
    return None

def hamming_distance(str1, str2):
    # Вычисление расстояния Хэмминга (количество несовпадающих бит)
    return sum(c1 != c2 for c1, c2 in zip(str1, str2))

# Сравниваем генотипы для близких фенотипов 0 и -0.01
gen_0 = "1000000000"
gen_minus_001 = "0111111111"

dist = hamming_distance(gen_0, gen_minus_001)
print(f"Расстояние Хэмминга между генотипами 0 и -0.01 составляет: {dist} бит!")
print("Это пример 'хэммингова обрыва' — близкие числа кодируются противоположными битами.")
```

### 2. Моделирование траектории эволюционного поиска (De Jong F1)


### Условие

Каждая хромосома представлена прямоугольником, цвет которого указывает на её уровень приспособленности. Цвета меняются от красного для плохой (высокой) приспособленности до синего для хорошей (низкой, так как задача на минимизацию) приспособленности. Порядок проекции для картирования пространства поиска берется от старшего бита для каждого измерения задачи: (0, 11, 21, 1, 12, 22 ...).

### Решение

Функция Де Жонга F1 для трех измерений (сферы) математически задается как:
\[f(x,y,z)=x^{2}+y^{2}+z^{2}\]


Напишем программу, имитирующую популяционный сдвиг от случайного начального распределения (высокий штраф, красный цвет) к оптимальной точке минимума (синий цвет) по поколениям. 
```python
import random

def de_jong_f1(x, y, z):
    return x**2 + y**2 + z**2

def simulate_generation_step(generation, pop_size=10):
    # Эмулируем сжатие популяции вокруг оптимума с течением времени
    # На 0 поколении разброс огромный, к 81 поколению все сходятся к 0
    sub_range = max(0.01, 5.0 - (generation * 0.07))
    
    population_fitness = []
    for _ in range(pop_size):
        x = random.uniform(-sub_range, sub_range)
        y = random.uniform(-sub_range, sub_range)
        z = random.uniform(-sub_range, sub_range)
        
        fit = de_jong_f1(x, y, z)
        population_fitness.append(fit)
        
    return population_fitness

# Снимаем метрики для 0 поколения и финального 81 поколения
gen_0_fits = simulate_generation_step(generation=0)
gen_81_fits = simulate_generation_step(generation=81)

print(f"Поколение 0 (Высокие штрафы, 'Красная' зона): Средний фитнес = {sum(gen_0_fits)/len(gen_0_fits):.2f}")
print(f"Поколение 81 (Минимум, 'Синяя' оптимальная зона): Средний фитнес = {sum(gen_81_fits)/len(gen_81_fits):.4f}")
```

### 3. Фильтрация и селективный фокус на регионах ландшафта


### Условие

Gonzo может использоваться для фокусировки на отдельных изолированных областях ландшафта приспособленности. Фильтрация позволяет отобразить исключительно те хромосомы, показатели приспособленности которых попадают в строго заданный интересующий исследователя диапазон.

### Решение

Чтобы анализировать поведение ГА в процессе долгого прогона, разработчики сохраняют историю всех рассмотренных точек (лог хромосом) и фильтруют их, отсекая неэффективные решения. Это помогает локализовать зоны ландшафта, где алгоритм застревает (локальные оптимумы). 
```python
def filter_chromosomes_by_fitness(history_logs, min_acceptable_fit, max_acceptable_fit):
    # Фильтрация накопленной базы данных хромосом для выделения целевых зон
    filtered_results = []
    for chromosome_data in history_logs:
        fitness = chromosome_data["fitness"]
        if min_acceptable_fit <= fitness <= max_acceptable_fit:
            filtered_results.append(chromosome_data)
    return filtered_results

# Имитируем лог работы алгоритма, содержащий хромосому и ее оценку
mock_history = [
    {"genotype": "1101001101", "fitness": 45.2},
    {"genotype": "1000000111", "fitness": 12.8},
    {"genotype": "1000000001", "fitness": 0.05},
    {"genotype": "0111111111", "fitness": 0.06},
    {"genotype": "0010110100", "fitness": 89.1}
]

# Выделяем только высокоприспособленные особи (близкие к идеальному минимуму 0)
elite_zone = filter_chromosomes_by_fitness(mock_history, min_acceptable_fit=0.0, max_acceptable_fit=1.0)

print("Отфильтрованные хромосомы, попавшие в оптимальный диапазон приспособленности (0.0 - 1.0):")
for item in elite_zone:
    print(f" -> Генотип: {item['genotype']} | Значение фитнеса: {item['fitness']}")
```
