### 1. Простой ГА для функции Onemax


### Условие

Реализуйте Простой Генетический Алгоритм (Simple Genetic Algorithm) для решения функции Onemax. Программа должна принимать в качестве параметров размер популяции \(N\), вероятность кроссовера \(\chi \), вероятность мутации \(\mu \) и размер задачи \(\ell \).

### Решение

Функция Onemax считает количество единиц в бинарной строке. Простой ГА инициализирует случайную популяцию, оценивает приспособленность, проводит селекцию (например, рулетку), применяет одноточечный кроссовер с вероятностью \(\chi \) и побитовую мутацию с вероятностью \(\mu \).

```python
import random

def onemax(chromosome):
    return sum(chromosome)

def create_population(n, l):
    return [[random.randint(0, 1) for _ in range(l)] for _ in range(n)]

def selection(pop, fitnesses):
    total = sum(fitnesses)
    if total == 0:
        return random.choice(pop)
    r = random.uniform(0, total)
    current = 0
    for ind, fit in zip(pop, fitnesses):
        current += fit
        if current >= r:
            return ind
    return pop[-1]

def crossover(p1, p2, l, cx_pb):
    if random.random() < cx_pb:
        point = random.randint(1, l - 1)
        return p1[:point] + p2[point:], p2[:point] + p1[point:]
    return p1.copy(), p2.copy()

def mutate(chrom, mut_pb):
    for i in range(len(chrom)):
        if random.random() < mut_pb:
            chrom[i] = 1 - chrom[i]

def run_ga(n, cx_pb, mut_pb, l, generations=50):
    pop = create_population(n, l)
    for _ in range(generations):
        fitnesses = [onemax(ind) for ind in pop]
        if max(fitnesses) == l:
            break
        new_pop = []
        for _ in range(n // 2):
            p1 = selection(pop, fitnesses)
            p2 = selection(pop, fitnesses)
            off1, off2 = crossover(p1, p2, l, cx_pb)
            mutate(off1, mut_pb)
            mutate(off2, mut_pb)
            new_pop.extend([off1, off2])
        pop = new_pop
    best = max(pop, key=onemax)
    return best, onemax(best)

# Пример запуска: N=20, cx_pb=0.7, mut_pb=0.01, L=10
print("Лучшее решение:", run_ga(20, 0.7, 0.01, 10))
```

### 2. Эффекты мутации при стандартном и рефлексивном коде Грея


### Условие

Вычислите математическое ожидание абсолютного отклонения закодированного целого числа, полученного в результате однократной равномерно выбранной точечной мутации в 4-геновом бинарном хромосоме, при стандартном бинарном кодировании и при рефлексивном бинарном кодировании Грея. Также вычислите дисперсию этого математического ожидания. Напишите компьютерную программу для помощи, если необходимо. *Подсказка:* Вопрос в том, если мутировать случайный ген в случайно выбранной хромосоме, какова ожидаемая разница в целом числе, которое эта хромосома кодирует до и после мутации? Математическое ожидание — это то же самое, что среднее значение. Ожидание должно браться по всем возможным одноточечным мутациям всех возможных хромосом, и по определению точечной мутации все мутации равновероятны. Предположим, что все хромосомы также равновероятны. Дисперсия \(\sigma ^{2}\) может быть вычислена как: \[\sigma ^{2}=\frac{\displaystyle \sum _{k}^{n}(x_{k}-\mu _{X})^{2}}{n},\]

где \(x_{k}\) — это отдельное значение, используемое при расчете математического ожидания, а \(\mu _{X}\) — само среднее или ожидаемое значение (т.е. \(\mu _ { X } = E ( X )\)). 

### Решение

Каждая из 16 хромосом длины 4 может мутировать в одном из 4 положений, что дает \(16 \times 4 = 64\) возможных сценария изменений. При стандартном кодировании изменение бита на позиции \(p\) (от 0 до 3) всегда меняет число на \(2^{p}\). Среднее отклонение составляет:
\[\mu _{std}=\frac{1+2+4+8}{4}=3.75\]


При кодировании Грея знак и величина изменения зависят от текущего состояния хромосомы. Компьютерный симуляционный расчет дает точные значения для обоих методов. 

```python
def binary_to_gray(n):
    return n ^ (n >> 1)

def gray_to_binary(g):
    b = 0
    while g > 0:
        b ^= g
        g >>= 1
    return b

def analyze_encoding(use_gray=False):
    diffs = []
    for i in range(16):
        chrom = binary_to_gray(i) if use_gray else i
        for pos in range(4):
            mutated_chrom = chrom ^ (1 << pos)
            mutated_decoded = gray_to_binary(mutated_chrom) if use_gray else mutated_chrom
            diffs.append(abs(mutated_decoded - i))
    
    mean = sum(diffs) / len(diffs)
    variance = sum((x - mean) ** 2 for x in diffs) / len(diffs)
    return mean, variance

mean_std, var_std = analyze_encoding(use_gray=False)
mean_gray, var_gray = analyze_encoding(use_gray=True)

print(f"Стандартное бинарное кодирование: Среднее = {mean_std}, Дисперсия = {var_std}")
print(f"Кодирование Грея: Среднее = {mean_gray}, Дисперсия = {var_gray}")
```

### 3. Разреженность перестановочного кодирования


### Условие

Для задачи, решениями которой являются перестановки из 5 объектов, какая доля хромосом, закодированных с использованием одного гена на позицию в перестановке, являются валидными решениями? Выведите общее выражение для кодирований с длиной хромосомы \(\ell \) генов и аллелей. 

*Подсказка:* Существует простой способ подсчета количества перестановок множества из \(n\) элементов, и вы должны быть знакомы с подсчетом количества уникальных строк длины \(\ell \) в заданной системе счисления (базе).

### Решение

Для 5 объектов длина хромосомы составляет \(\ell = 5\), и на каждой позиции может быть один из 5 аллелей (база 5). 

- Общее число возможных строк (хромосом): \(5^5 = 3125\).
- Число валидных перестановок: \(5! = 120\).
- Доля валидных решений: \(\frac{120}{3125} = 0.0384\) (или \(3.84\%\)).

Общая формула для \(\ell \) генов и \(\ell \) аллелей (квадратная матрица пространства поиска):
\[P=\frac{\ell !}{\ell ^{\ell }}\]


```python
import math

def permutation_sparsity(l):
    valid = math.factorial(l)
    total = l ** l
    proportion = valid / total
    return proportion

l_objects = 5
prop = permutation_sparsity(l_objects)
print(f"Доля валидных хромосом для {l_objects} объектов: {prop:.4f} ({prop*100:.2f}%)")
```

### 4. Позиционное смещение операторов кроссовера


### Условие

Вычислите вероятность того, что два аллеля, между которыми находится \(l\) генов, на родительской хромосоме длины \(\ell \), окажутся вместе в одной и той же дочерней хромосоме для 1X (одноточечного), 2X (двухточечного) и UX (однородного) кроссовера с произвольной вероятностью \(p\) (предполагается, что операторы кроссовера создают двух потомков). *Подсказка:* Для каждого оператора разберите все возможные ситуации, в которых оба аллеля попадают в одну дочернюю хромосому. Вычислите вероятность каждой из этих ситуаций. 
### Решение

Пусть два гена находятся на позициях \(A\) и \(B\). Расстояние между ними (количество промежутков между генами) равно \(l = \vert{}A - B\vert{}\). Всего в хромосоме длины \(\ell \) существует \(\ell - 1\) возможных точек разреза. 

- **1X (Одноточечный):** Гены останутся вместе, если точка разреза НЕ попадет между ними. Количество точек между ними равно \(l\). Вероятность разреза между ними равна \(\frac{l}{\ell -1}\). Следовательно, они останутся вместе с вероятностью: \[P(1X)=1-\frac{l}{\ell -1}\]
- **2X (Двухточечный):** Гены останутся вместе, если обе точки разреза упадут либо до гена \(A\), либо после гена \(B\), либо обе попадут между ними. Проще посчитать противоположное событие: разрез разделяет их, если ровно одна точка падает между ними. Вероятность этого равна \(2 \cdot \frac{l}{\ell-1} \cdot \frac{(\ell-1) - l}{\ell-2}\). Итоговая вероятность сохранения: \[P(2X)=1-\frac{2l(\ell -1-l)}{(\ell -1)(\ell -2)}\]
- **UX (Однородный/Uniform):** Каждый ген наследуется независимо от конкретного родителя с вероятностью \(p\) (и от второго с вероятностью \(1-p\)). Потомков двое, поэтому гены окажутся вместе, если оба унаследуются от Родителя 1 (вероятность \(p \cdot p\)) или оба от Родителя 2 (вероятность \((1-p) \cdot (1-p)\)): \[P(UX)=p^{2}+(1-p)^{2}\]


```python
def prob_together_1x(l_dist, L_len):
    return 1.0 - (l_dist / (L_len - 1))

def prob_together_2x(l_dist, L_len):
    if L_len <= 2: return 1.0
    prob_separated = (2 * l_dist * (L_len - 1 - l_dist)) / ((L_len - 1) * (L_len - 2))
    return 1.0 - prob_separated

def prob_together_ux(p):
    return p**2 + (1 - p)**2

# Пример для L=10, расстояния l=3 между генами и p=0.5 для UX
print(f"Вероятность сохранения вместе (1X): {prob_together_1x(3, 10):.3f}")
print(f"Вероятность сохранения вместе (2X): {prob_together_2x(3, 10):.3f}")
print(f"Вероятность сохранения вместе (UX): {prob_together_ux(0.5):.3f}")
```
